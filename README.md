# Manikandan M — Profile

A personal portfolio presenting Manikandan M's career journey at IBM from 2022 to 2026. The page combines an interactive career timeline with project highlights, achievements, and digital badges.

## Features

- Interactive career timeline with milestone navigation and an auto-travel tour
- Searchable milestones
- Expandable digital badge gallery
- Links to LinkedIn and Dev.to
- Responsive, self-contained HTML page

## Project structure

```text
docs/
├── index.html
├── badges_overview.jpg
└── profile.png
```

The images are used by the profile page and should remain alongside `index.html`.

## View locally

Open [`docs/index.html`](docs/index.html) in a web browser. The page has no build step or package dependencies. An internet connection is needed to load the Google Fonts used for typography.

## Publish with GitHub Pages

In the repository's **Settings → Pages**, configure the deployment source to use the `main` branch and `/docs` folder.
